# Built-in initialization, runtime, removal and NOR contract

The additive gate executes 368 fixed typed observations in ten inert static MIPS models: RAETH45, NOR31, proc29, runtime51, QTX31, ioctl78, reset_core17, MDIO34, remove20 and ESW32. All 259 preceding observations remain unchanged, with additive runtime/ioctl cases. It renders 98 complete function entries (92 distinct), 17 source-only entries and two separate references from 57 logical source inputs. Source Python is parsed as literal AST data, never imported or called.

Thirteen real objects and commands, their required aggregate members, 48 unique implementation symbols and the linked vmlinux are bound to the same independently image-bound kernel. Stable owners include mii_mgr_read/write/read_cl45/write_cl45, raether_remove, device_release_driver, reset_control_reset and esw_ioctl_init_post. Optimized-away helpers do not require invented standalone symbols. The shipping profile requires built-in RAETH/NOR, MT7621, little endian, reset-controller and ESW support; forced ETHTOOL wrappers in the MDIO model remain disabled in the shipping profile.

The original bookkeeping, NOR admission, proc retirement, runtime DMA ownership, QDMA TX transaction and ioctl guards remain covered. DMA mappings, rings, MMIO mappings, parent-device and netdev ownership survive failed stop/idle cleanup. The remove model executes the actual driver-core release body and observes that driver-core ignores the callback return and clears drvdata; explicit non-devm ownership protects the retained graph. Selected callbacks and reference-count transitions are inert seams, not physical removal or arbitrary kernel concurrency proof.

MDIO executes bounded polling with frozen ticks and full ordered 32-bit controller commands, Clause22/45 address/data failure propagation, and selected pthread detach/indirect-transaction schedules. The model forces three ETHTOOL wrappers for error propagation coverage; they are not shipping K2P objects. ESW executes the real MAC-clear wait/helper/wrapper, bridge selection, post-init and ioctl functions; VLAN programming and power effects are explicit source-bound seams. Runtime additionally executes the post-init error path before DMA starts. Reset-core uses a sequential atomic shim for the compiled shared-reset API retry bug; this board has no current shared-reset caller.

Base -Wall/-Wextra/-Werror flags remain unchanged for all preceding components. Only the MDIO model appends -Wno-unused-parameter, and only ESW appends -Wno-unused-variable, -Wno-unused-parameter and -Wno-unused-but-set-variable. These exact literal component options account for synthetic seams and are checked by the independent acceptor; they do not change production compilation or suppress other diagnostics.

Early static MIPS preflight and final same-image SPI reference are mandatory. The actual compiled config must equal the embedded image config. Userspace models do not establish physical DMA drainage, real Linux callback/RTNL ABI, arbitrary scheduling, hot reset, whole-system memory pressure or efd2 first-upgrade safety. No router operation is performed.
