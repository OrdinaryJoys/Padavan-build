# Current initialization and DMA lifecycle contract

This gate executes 106 fixed, typed current control-flow observations (init61, DMA29, unwind16) in three inert static MIPS userspace adapters: software initialization, checked DMA APIs, and the first-arm failure/unwind chain. Its exact case selectors, expected rows, complete function mappings, literal model hashes, source inputs and object exports are declared in check_target_init_dma_lifecycle.py. Source generators are parsed as literal data, never imported or called.

PASS means that every specified observation matches. It does not mean all DMA teardown risks are fixed. In particular, the perpetually busy ordinary teardown and first-arm unwind cases deliberately expose the still unresolved legacy release policy. The report retains known_busy_teardown_release_gap=true and exact unsafe-release observations. A failed idle result must not be described as a verified drain barrier.

The three adapters copy 44 complete function entries (42 distinct functions) whole, in BODY_ORDER. Fifteen source-only outer entries are separately labeled. The input inventory is 51 entries; final binding requires 22 actual objects and their 22 commands, with 53 uniquely present required implementation symbols. SOURCE_DECLARATIONS reads unique complete declarations from the locked actual headers; source NDIS values and the checked firmware initialization callback type are bound separately. Complete source-only outer functions are retained under source_contract.outer_function_manifest with execution=source-only-not-run. They are not represented as executed C.

Early mode:
    --trunk PATH --compiler PATH --output PATH/target-init-dma-lifecycle.json --preflight

Final mode replaces --preflight with --wifi-report PATH/target-wifi-factory.json. Final mode requires completed same-source/configuration Factory49, actual built and shipped modules and the same image identity. Each required object, its complete .cmd compiler selection and the aggregate/module link commands must match. Required function symbols must be uniquely present in actual object and module ELF bytes. This is a clean-build provenance binding, not independent compilation or relocation replay.

Every complete stdout JSON line is exported. The offline independent acceptance code checks exact typed/order observations, regenerated current C, fixed C hashes, static MIPS ELF metadata, complete-body manifests, bounded ordinary evidence files, parent/image/module identities and actual symbol membership without executing B/S generators, compiler, target, device or module.

Current module scope requires K2P 4.4 little-endian MT7615, RESOURCE_PRE_ALLOC, ERR_RECOVERY, KTHREAD, tasklet, FAST_PATH_QM and the actual core MT_MAC/CONFIG_AP_SUPPORT/DOT11_N_SUPPORT/CONFIG_TX_DELAY flags. Board CONFIG_WSC_INCLUDED and V2 are disabled, and actual commands must not define WSC support, CONFIG_PROPRIETARY_DRIVER or RT_BIG_ENDIAN. config.mk defaults do not override the selected board/Makefile/.cmd evidence. The separate WSC-enabled AP/APCLI/V2 20-case native source model is not represented as shipping MIPS WSC code. Complete source copies use reduced inert preprocessor seams for selected ownership/error paths; other enabled production ATE/UAPSD/MAT and optional branches are not all executed by these userspace probes. Private allocation/task/lock/reference models and inert register operations do not execute kernel tasks, DMA, hardware reset or a physical bus. Other chipset/configuration branches, full close/remove quarantine, all concurrent teardown owners, bus transactions in flight, cold/warm reset, global memory peak and efd2 first-hop execution remain outside this software acceptance.

No router connection, device/MTD access, firmware write or reboot is performed.
