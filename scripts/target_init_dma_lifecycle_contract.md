# Initialization, DMA containment and prepublication resource contract

This gate executes 489 fixed typed observations in ten inert static MIPS userspace adapters: initialization72, DMA29, first-arm unwind22, quarantine39, command40, VIF28, probe78, CMWQ42, resource85 and wdev54. The exact selectors, expected rows, complete function maps, source inputs and model-data hashes are literal fixed contracts. Source generators are AST-parsed as data and never imported or called by this gate.

The adapters copy 181 complete function entries (162 distinct functions) in their locked BODY_ORDER. Fifty-nine component source-only function entries and five separate kernel module reference functions are explicitly source-only-not-run. The inventory has 150 logical inputs. Final binding requires 39 distinct real driver objects, all 39 .cmd files and 143 unique required implementation symbols, linked through the aggregate and built/shipped module to the same image. Static helpers which naturally inline bind by complete source-model bodies and fresh containing objects/global callers; no independent relocation replay or separate optimized-away symbol claim is made.

Failed stop/idle/reset retains the complete adapter, ring/token, IRQ, netdev, BAR, PCI-device and module owner graph. Terminal stop closes DMA, command and scheduling admission before execution retirement. Cached quiescence is rechecked against task/IRQ/running owners. Cleanup failure must preserve the remaining graph and propagate the failure through generic task, HIF, ready, close and remove paths. Retained drvdata rejects reprobe before PCI enable; the actual shared-IRQ shim rejects quarantined callbacks before dispatch. Holding an independent PCI object reference cannot veto physical topology removal or platform resource release.

The probe adapter models atomic unpublished construction and cleanup, including stats allocation, HDEV/RLM/WPF stages, cookie transfer, netdev and PCI rollback. MODEL_VARIANT is independently fixed in SOURCE_ABI. The probe model forces MULTI_INF_SUPPORT to exercise late constructor-registration failure; actual K2P commands must not define it. MSI is off in the default MIPS adapter and actual board configuration. An extra native MSI variant tests acquired-MSI cleanup; it is not execution of a shipping MSI driver. Reduced IE/WPF counts and OS abstraction seams are explicit model choices, not real adapter layout.

The probe adapter also copies complete current beacon initialization and destruction functions. Packet allocation failure returns before content-lock ownership is acquired. An initialized same-owner beacon reuses its live packet and lock; foreign ownership or a missing packet rejects the attempt. Destruction without content-lock ownership releases independent packet/TIM allocations without touching locks, under the retired-caller precondition. Repeated destruction has no remaining owners to release. Source checks require direct access to the embedded PciHif, flag acquisition and release in order, and beacon destruction for every embedded MBSSID array slot before every adapter lock and HDEV retirement. The slot bound is independent of the current or reduced BssidNum; three additional fixed cases cover sparse, reduced-count and uninitialized slots. Final binding requires bcn_buf_init and bcn_buf_deinit in embedded/common/bcn.o and the linked module. MT7615's HIF_MT selection is a runtime chip capability using the real enum; it is never a -DHIF_MT command-line selection. Packet, lock and runtime-capability effects use inert model seams and do not establish hardware execution or real kernel ABI.

CMWQ code is compiled into the nonproprietary driver; actual K2P runtime capabilities choose TASKLET for QM/HIF. Eight actual CMWQ static callback entrypoints are required in tm.o and the linked module. The separate CMWQ userspace adapter executes complete state, publish, scheduling, cancellation and destruction functions with real pthread interleavings and inert queue/allocation/IRQ seams. SOURCE_FIELD_CONSTRAINTS insert uniquely matched state-field declarations at STATE_FIELDS; SOURCE_DECLARATIONS insert complete declarations at SOURCE_DEFINITIONS. Each marker is required exactly once when used. This does not execute Linux workqueues or prove all kernel schedules.

The resource adapter executes 17 complete WMM/HDEV/chipcap/device-control/PCIe functions. PCI7 and current IP_ASSEMBLY CMM6 heap failure points self-rollback; the wrapper only releases PCI owners obtained by its own attempt. DevCtrl14 heap failures, ring and chip-hook failures, duplicate owners, retry, final-release refusal and stale PCI success inputs are fixed observations. The model uses two TX/RX rings and reduced structs, and omits optional AP/ATE preprocessor branches despite actual CONFIG_AP_SUPPORT being enabled. Rc/Wtc, chip hook, PCI configuration, ring/DMA allocation, final-release decision and final adapter destruction are explicit seams. Separate existing startup/probe/quarantine gates bind their applicable implementations. The private model observes intentionally retained heaps before private fixture cleanup; it never substitutes that fixture cleanup for production recovery.

The wdev adapter executes 15 complete current functions covering netdev/wdev publication, MBSS initialization/removal, close-all retirement admission and vendor-IE heap transactions. All registered interfaces stay live until close-all confirms zero VIF count, stopped tasks/queues/timers and final DMA release admission. Failed retirement retains configuration, wdev and netdev owners. The published primary wdev is explicitly deinitialized after its netdev detaches, releasing its VIE/operate/HDEV owners once; configuration links retire only after child and primary netdev detachment and wdev retirement. MBSS removal preserves cached beacon owners for final adapter destruction. Vendor-IE node and payload allocations stay private until both succeed, and failed replacement preserves the old chain/count/payload. Three MBSSID/WDEV slots replace target maxima; real RTNL, dev_close, unregister, task joins and heap effects are private seams. Current APCLI is enabled and its object/caller is bound but its full initialization function remains source-only in this adapter. WDS and SNIFFER callers remain disabled/source-only. Selected callback interleavings are not real Linux scheduling or a complete external-caller lifetime proof.

Normal/FWDL command publication, per-sender queue ownership, completion/clone cleanup and VIF paired INIT→UP rollback remain covered. Actual configuration requires little-endian K2P4.4, MT7615, LINUX, RESOURCE_PRE_ALLOC, ERR_RECOVERY, IP_ASSEMBLY, KTHREAD, TASKLET, FAST_PATH_QM, APCLI and MBSS. Actual objects must not define FQ_SCH_SUPPORT, BLOCK_NET_IF, COMPOS_TESTMODE_WIN, MULTI_INF_SUPPORT, CONFIG_WIFI_MSI_SUPPORT, WSC, CONFIG_PROPRIETARY_DRIVER, RT_BIG_ENDIAN, WDS_SUPPORT, CONFIG_SNIFFER_SUPPORT or SNIFFER_SUPPORT. config.mk defaults alone do not establish the selected board/Makefile/.cmd profile. GNU strict native and Clang ASan/UBSan suites additionally run private protection-removal controls.

Early mode uses --preflight; final mode instead requires --wifi-report and the completed same-source/configuration Factory49 parent, actual object commands, aggregate/module links and built/shipped same-image identities. Kernel module reference and disabled-force-unload branches remain source-only evidence. PASS does not establish real PCI in-flight drainage, full IRQ/RTNL/kernel callback ABI, every external raw caller lifetime, physical reset, whole-system memory pressure or efd2 first-hop safety. No router connection, device/MTD access, firmware write or reboot is performed.
